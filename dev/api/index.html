Dynspec.Analysis.residuals — Function
residuals(block::AbstractModelBlock; filter_by=nothing, at=nothing) -> Vector{Float64}

Compute equation residuals directly on the parsed AST equations.

  • filter_by: filter equations by tag (:transition), tags ([:transition, :arbitrage]), or predicate.
  • at: overrides for variables (e.g. (:z, 0) => 0.1 or :z => 0.1) or constants (:α => 0.36).
source
Dynspec.Analysis.jacobian — Function
jacobian(block::AbstractModelBlock; wrt, filter_by=nothing, at=nothing)

Compute analytical Jacobian(s) with respect to wrt. If wrt is a flat vector of targets, returns a single Matrix{Float64}. If wrt is grouped (vector of vectors), returns a Tuple of Matrix{Float64}.

source
Dynspec.Analysis.derivatives — Function
derivatives(block::AbstractModelBlock; wrt, filter_by=nothing, at=nothing)

Compute equation residuals and analytical Jacobians with respect to wrt.

  • Bare symbols (:α, :β) represent constants/parameters.
  • Tuples ((:z, 0), (:k, -1)) or TimedVars represent variables with time shifts.
  • If wrt is grouped (e.g. [ [(:z,0), (:x,0)], [(:z,1), (:x,1)] ]), returns (residuals, (J1, J2, ...)).

Dyno Submodule (DSGE Perturbation)

Dynspec.Dyno — Module
Dyno

Submodule containing DSGE perturbation matrix extractors and model helpers.

source
Dynspec.Dyno.first_order_model — Function
first_order_model(block::AbstractModelBlock; filter_by=nothing, endogenous=nothing, exogenous=nothing, at=nothing)

Construct a first-order DSGE model representation as a NamedTuple:

  • symbols: NamedTuple of variable and parameter groups:
    • endogenous: ordered list of endogenous variable symbols
    • exogenous: ordered list of exogenous shock symbols
    • constants: ordered list of constant / parameter symbols
  • residuals: residual vector evaluated at steady state (or at)
  • jacobians: NamedTuple of first-order Jacobians:
    • A: ∂f / ∂y_{t+1} (lead)
    • B: ∂f / ∂y_t (current)
    • C: ∂f / ∂y_{t-1} (lag)
    • D: ∂f / ∂e_t (shocks)
source
Dynspec.Dyno.endogenous_exogenous — Function
endogenous_exogenous(block::AbstractModelBlock; endogenous=nothing, exogenous=nothing)
    -> (endogenous = Vector{Symbol}, exogenous = Vector{Symbol})

Extract the ordered lists of endogenous and exogenous variables from block. If not explicitly provided, exogenous variables are inferred from declared processes and endogenous variables from steady states and equation variable occurrences.

source
Dynspec.Dyno.compute_dsge_jacobians — Function
compute_dsge_jacobians(block::AbstractModelBlock; filter_by=nothing, endogenous=nothing, exogenous=nothing, at=nothing)
    -> (residuals, A, B, C, D)

[TEMPORARY / CONVENIENCE HELPER] Evaluate residuals and compute standard first-order perturbation matrices for DSGE solvers:

  • A = ∂f / ∂y_{t+1}
  • B = ∂f / ∂y_t
  • C = ∂f / ∂y_{t-1}
  • D = ∂f / ∂e_t
source
Dynspec.Dyno.solve_dsge — Function
solve_dsge(A::AbstractMatrix, B::AbstractMatrix, C::AbstractMatrix, D::AbstractMatrix; max_iter::Int=50, tol::Float64=1e-11) -> (P, Q)

Solve the first-order linear DSGE system: A * Et[y{t+1}] + B * yt + C * y{t-1} + D * et = 0 using cyclic reduction to find the stable recursive law of motion matrices P and Q: yt = P * y{t-1} + Q * et

source

Dynspec.Dyno.simulate_linear — Function
simulate_linear(P, Q; T=40, shocks=nothing, shock_idx=1, shock_size=1.0) -> Matrix{Float64}

Simulate the linear system y_t = P * y_{t-1} + Q * e_t for T periods. If shocks is omitted, computes the Impulse Response Function (IRF) to a one-time shock of shock_size on shock shock_idx at t=1. If shocks is an n_shocks × T matrix, simulates under that shock sequence.
